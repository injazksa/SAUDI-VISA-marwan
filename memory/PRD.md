# PRD — مكتب المتخصصون لإنجاز معاملات السفارة السعودية

## Original Problem Statement
بناء منصة/موقع جديد باسم وهوية جديدة (سعودية أخضر/أبيض) لمكتب مرخّص ومعتمد من السفارة السعودية في الأردن، مختص بإنجاز معاملات تأشيرات العمل وتصديق الشهادات والوثائق والاعتماد المهني (QVP). المطلوب: محتوى غني حقيقي يوزَّع على الصفحات والبطاقات، قسم «من نحن» مبكراً، إبراز الترخيص والاعتماد في كل المواضع التعريفية (بدون أرقام تراخيص مختلقة أو وعود بضمان الموافقة)، إزالة الأرقام الزخرفية 01/02، تصميم احترافي فاخر، عربي RTL كامل، سيو، سرعة، تجاوب ممتاز.

## Architecture
- Frontend: React (CRA + craco), Tailwind, framer-motion, lenis, react-router. RTL كامل.
- المحتوى: `/src/lib/content.js` (النصوص العامة + 8 مقالات + 14 سؤالاً) و `/src/lib/services.js` (بنية blocks غنية لكل خدمة: lead/steps/checklist/docGroups/compare/features/article/faq/cta/note/docs).
- الصفحات: Home (مرتبة: Hero←Marquee←About←Accreditation←Services←Process←Blog←Faq←Contact)، /services/:slug (4 صفحات غنية + breadcrumbs + شارة اعتماد)، /blog/:slug (8 مقالات)، صفحات قانونية، 404.
- نشر Netlify: netlify.toml + public/_redirects. سيو: sitemap.xml, robots.txt, llms.txt, JSON-LD (LocalBusiness+WebSite+FAQPage محدّثة في index.html، وService+BreadcrumbList ديناميكياً).
