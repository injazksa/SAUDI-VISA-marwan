# PRD — مكتب المتخصصة لإنجاز معاملات السفارة السعودية

## Original Problem Statement
بناء منصة/موقع جديد باسم وهوية جديدة (سعودية أخضر/أبيض) مستوحى من دليل "إنجاز السعودية"، لمكتب معتمد ومرخص لإنجاز معاملات السفارة السعودية في الأردن. المطلوب: هيدر جميل، سلايدر صور، تصميم مميز يناسب جميع الأجهزة، صفحات سياسة خصوصية وشروط استخدام بصياغة قانونية، صفحة "من نحن" بكلمات مفتاحية قوية للسيو، سرعة وترتيب ممتاز. الاسم: "مكتب المتخصصة لإنجاز معاملات السفارة السعودية" وتحته "مكتب معتمد للسفارة السعودية في الأردن".

## Architecture
- Frontend: React (CRA + craco), Tailwind, framer-motion, lenis (smooth scroll), react-fast-marquee, lucide-react. RTL كامل.
- Backend: قالب FastAPI الافتراضي فقط (غير مستهلك من الواجهة). لا يوجد تكامل خارجي.
- موقع صفحة واحدة (Home) + 3 مسارات قانونية: /privacy, /terms, /disclaimer.
